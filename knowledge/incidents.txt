Incident: Payment Service High Latency
Symptoms: p99 API latency above 2000ms; requests slow; database connection pool exhaustion.
Possible cause: database connection pool exhaustion.
Recommended checks: Check active database connections; check slow database queries; review deployments.

Incident: High API Error Rate
Symptoms: HTTP 5xx errors exceed five percent; downstream dependency unavailable.
Possible cause: downstream dependency unavailable.
Recommended checks: Check downstream health; inspect HTTP status and logs.

Incident: High CPU Usage
Symptoms: application CPU usage over 90 percent; hot loop or traffic spike.
Possible cause: hot loop or traffic spike.
Recommended checks: Profile expensive endpoints; inspect host CPU and traffic.

Incident: Kafka Consumer Lag

Possible cause: Kafka partition lag increasing.
Recommended checks: Inspect consumer offset lag; processing throughput and rebalances.
